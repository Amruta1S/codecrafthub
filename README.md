# CodeCraftHub

## Overview
CodeCraftHub is a simple **personalized learning platform** for developers. Track courses you want to learn, their target completion dates, and status. Built for beginners to learn **REST APIs with Flask**.

---

## Features
- Add, view, update, and delete courses
- Store data in a simple JSON file (`courses.json`)
- Track course status: **Not Started**, **In Progress**, **Completed**
- View statistics about courses
